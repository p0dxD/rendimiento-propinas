# rendimiento-propinas

Una página para repartir la cuenta y la propina entre amigos, al centavo: todo se cuenta en centavos enteros, y los que no se dividen parejo los pagan las primeras personas, uno cada una.

- `npm start`: el servidor en el puerto `PORT` (3000 si no se dice).
- `npm test`: las pruebas.
- `GET /api/repartir?cuenta=100&propina=15&personas=3`: el reparto en JSON.

Desplegada con [rendimiento.ai](https://rendimiento.ai).
